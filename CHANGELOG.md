# Change log

Each section lists the changes of one released version. The release workflow
takes the section of a version as the notes of its GitHub release.

## 0.4.2

- A short description for the Marketplace listing.

## 0.4.1

- First release on the Visual Studio Marketplace under the extension ID
  `nimblescape.comment-markdown-links` and the display name
  "nimblescape Comment Markdown Links".
- The setting that hides link targets is
  `nimblescape.commentMarkdownLinks.hideTargets`, the name of the earlier
  private builds.

## 0.4.0

- GitHub release only, under the extension ID `nimblescape.markdown-links`
  with the setting `nimblescape.markdownLinks.hideTargets`. The Marketplace
  rejected the name, because another extension uses it. Uninstall this
  version before you install 0.4.1.
